# Regan K.C. — Cybersecurity Portfolio

Personal portfolio of **Regan K.C.**, a BITM student and security-focused developer based in Hetauda, Nepal.

The portfolio presents my work across cybersecurity, backend development, AI-assisted tools, and practical web applications. Its core purpose is to demonstrate how I approach security: **secure by default, practical to implement, and clear to understand**.

## Core Concept

This portfolio is designed as a professional introduction to my technical work and cybersecurity direction. It combines:

- Security-focused projects and automation tools
- Practical cybersecurity services for individuals, small organizations, and development teams
- Defensive security and SOC-oriented capabilities
- A record of my education, training, and professional journey
- Open-source repositories and project case studies

My long-term focus is building reliable security tools and helping teams identify weaknesses, improve their security posture, and respond to threats more effectively.

## Services

### Technical and Freelance Services

- **Web Application Security Auditing** — Authenticated and unauthenticated testing aligned with the OWASP Top 10, followed by actionable remediation guidance.
- **Phishing and Email Security Setup** — SPF, DKIM, and DMARC configuration, supported by employee phishing-awareness playbooks.
- **System and Endpoint Hardening** — Linux and Windows baseline hardening, secure SSH configuration, and local firewall setup.
- **Code and Dependency Audits** — Reviews for hardcoded secrets, exposed credentials, and vulnerable dependencies.

### Defensive and SOC Analyst Services

- **Log Analysis and Detection Engineering** — Custom YARA, Sigma, and Suricata rules with Python or Bash-based log analysis.
- **SIEM Dashboard and Alert Configuration** — Log pipelines, dashboards, and alert views using platforms such as Wazuh and Elastic Stack.
- **Incident Response Playbook Design** — Practical triage and response workflows for ransomware, credential stuffing, and unauthorized API access.

All security testing is performed only with explicit authorization and within an agreed scope.

## Featured Projects

- **SOC Copilot** — Helps security teams triage noisy alerts, identify suspicious activity, and produce concise reports.
- **Phishing Detector** — Evaluates suspicious links and emails, assigns a risk score, and explains the indicators of compromise.
- **API Security Scanner** — Checks APIs for common security weaknesses such as missing authentication controls and unsafe configurations.
- **Coding Agent** — Performs coding tasks from natural-language instructions with project-aware and safety-conscious execution.
- **Triad** — Uses collaborating agents to assess software readiness and recommend a GO or HOLD release decision.

## Running Locally

### Prerequisites

- Node.js 20 or newer
- npm or Bun

### Development

```bash
npm run dev
```

The development server will start locally and provide a URL in the terminal.

### Production Build

```bash
npm run build
npm run preview
```

### Quality Checks

```bash
npm run lint
npm run test
```
